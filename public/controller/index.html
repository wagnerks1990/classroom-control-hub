School Calendar Rules

    
All calendar changes recalculate the Green/White A–H rotation from the fixed anchor 08/19/2026 = Green / Cycle A. One date per line, YYYY-MM-DD.

    
If a date appears in more than one category, priority is: No-School → Remote → Half Day → 2-Hour Delay → 1-Hour Delay.

    

      
      
      
      
      
    

    

    

  


  

    

      
Morning Announcements • Live Watch
On student school days, Classroom Control Hub watches the Ant Media stream during the morning window. When it becomes live, it takes all configured targets fullscreen with audio-on redundancy. When the stream ends, it clears the announcement and releases the displays back to the normal scheduler.

      Loading…
    

    

      
      
      
      
      
    

    

    
Targets: all enabled displays. Two consecutive offline checks are required before an active announcement is ended, preventing a brief stream hiccup from blanking the TVs.

How schedules work

    

      Classroom Control Hub checks the schedule every 15 seconds. Events can run on normal weekly weekdays, alternating A/B school days,
      or exact calendar dates. District no-school dates above are globally suppressed. A/B rotation counts
      only eligible Monday–Friday school days, so blocked dates do not advance the rotation. Events persist in
      /opt/classroom-control-hub/data/automations.json; calendar rules persist in /opt/classroom-control-hub/data/scheduler-calendar.json.
